# 내부 캘린더

주 메뉴 캘린더 또는 할 일 → 캘린더에서 월간·주간 보기를 사용합니다.
사용자 프로필의 시간대를 기준으로 예정 기간과 마감일을 각각 표시하며,
완료·취소한 할 일도 해당 날짜에 표시합니다. 삭제한 항목은 제외합니다.

날짜의 + 버튼으로 예정일을 지정해 추가하고 항목을 눌러 기존 할 일 편집창을 엽니다.
프로젝트·우선순위·태그 필터를 함께 사용할 수 있습니다.
월간은 일요일부터 6주, 주간은 일요일부터 7일을 표시합니다.
좁은 화면에서는 캘린더 안에서 가로로 스크롤합니다.
최대 500건을 조회하며 상한에 도달하면 안내합니다.

시간대별 날짜·다일 일정·독립된 마감일을 지원합니다.
시간 격자와 드래그 이동, Google Calendar 연동은 후속 범위입니다.
기존 날짜 편집창은 날짜 단위로 저장합니다.
