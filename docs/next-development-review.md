# 다음 개발 단계 재검토 (2026-10-23)

기준: `development-plan.md`의 단계 4·5와 현재 구현 파일을 대조했다. 아래 항목은 제안이며, 이번 변경에서 외부 서비스 연동이나 데이터 가져오기를 실행한 것은 아니다.

## 현재 완료된 범위

- 단계 0~3: 기본 로그인·개인 공간·할 일·노트·대시보드·자동화·반복 할 일. 운영 계정 설정과 실제 서비스 가동 상태는 코드 구현과 별개다.
- 일상 사용 보완: 오늘/내일 이동·내일 복사·과거 날짜 완료·모바일 입력 폭.
- 이번 변경: 할 일 편집 중 프로젝트 등록, 목록 상태 선택, 여러 단계 프로젝트 계층, 별도 상시 사업·활동 및 활동처 목록과 할 일 연결. 반복 회차와 복사에도 활동 연결 유지.
- 노트 화면의 검색은 있으나 `/search`의 통합 검색, `/calendar`·`/sharing`은 아직 안내 화면이다. DB 권한 기반이 있다고 공유 초대·공간 전환 UX가 완료된 것은 아니다.

## 이번 모델의 동작과 후속 선택

- 프로젝트는 마감 있는 작업 묶음으로 여러 단계 중첩 가능하다. 상위 변경 시 순환·다른 공간 연결을 차단한다. 부모를 삭제하면 직접 하위는 최상위로 이동하며, 할 일은 삭제하지 않는다. 복구하는 프로젝트도 최상위로 돌아온다.
- 현재 프로젝트 진행률과 상세 할 일은 **직접 연결된 할 일** 기준이다. 하위 프로젝트를 합산하는 지표는 별도의 제품 결정·쿼리 검증 후 추가한다.
- 상시 사업·활동은 프로젝트와 다른 목록이며 기한 필드가 없다. 활동처도 독립 목록이다. 활동의 기본 활동처를 할 일에서 자동 선택하되, 할 일마다 다른 활동처로 바꾸거나 비울 수 있다.
- 활동의 기본 활동처를 바꿔도 이미 연결된 할 일의 활동처를 덮어쓰지 않는다. 삭제 시 연결만 해제하고 할 일은 보존한다. 반복 시리즈의 삭제된 연결도 해제한다.
- 활동·활동처 삭제는 UI에서 확인을 받고 소프트 삭제한다. 30일 후 보존 정책에 따라 영구 정리한다. 사용자 복원 UI는 후속 데이터 관리 화면에서 제공할 수 있다.
- 외부 연동·초대·복원 도구는 각각 필요한 권한·비밀 값·대상 환경을 확인해야 한다. 개발 일정은 이 선행 조건과 샘플 데이터가 확보된 뒤 산정한다.
