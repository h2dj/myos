# 하위 프로젝트·관련 항목·추가 메모

## 프로젝트 상세에서 하위 추가

프로젝트 상세의 **하위 프로젝트 추가**를 누르면 현재 프로젝트가 상위로 지정됩니다. 저장 후 새 하위 프로젝트로 이동하며 상위 링크로 돌아갈 수 있습니다. 서버는 상위 프로젝트가 속한 공간과 쓰기 권한을 기준으로 생성합니다.

## 사업·활동 관계와 지식 연결

사업·활동/활동처 목록의 **관련 항목**에서 상세 연결 화면으로 이동합니다. 프로젝트·노트 상세와 할 일 상세/편집에도 관련 항목 영역이 있습니다.

- 사업·활동 ↔ 다른 사업·활동, 프로젝트: 관련 업무 관계를 양쪽에서 확인합니다.
- 지식·아이디어 ↔ 프로젝트, 사업·활동, 활동처, 할 일: 하나의 노트를 여러 항목에 연결할 수 있습니다. 먼저 노트를 저장한 뒤 연결합니다.
- 연결 유형을 선택하고 제목·이름으로 찾은 후 **연결 추가**를 누릅니다. 후보는 20개씩 검색하며 다음 결과를 탐색할 수 있습니다.
- 연결된 항목으로 이동해 역방향 연결도 확인합니다. **연결 해제**는 양쪽 관계만 제거하고 원본은 보존합니다.
- 노트의 기존 프로젝트 필드는 **기본 프로젝트 연결**로 표시하며 노트 편집에서 변경합니다. 노트에서 만든 할 일의 파생 연결은 별도로 표시하고 출처를 보존합니다. 기존 연결을 다시 추가해도 중복 생성하지 않습니다.

같은 공간의 살아 있는 항목만 연결합니다. 조회자는 읽기·검색만 할 수 있고 편집자·소유자는 추가·해제할 수 있습니다. 자기 연결·지원하지 않는 유형·공간 간 연결을 차단합니다. 삭제된 항목은 관련 목록과 검색에서 숨기며 영구 정리 시 관계도 제거합니다. 재정 데이터는 업무 관계 연결 대상에 포함하지 않습니다.

## 계좌·예산 설명과 추가 메모

계좌·예산 등록/수정 화면에서 기본 **설명**을 입력합니다. 용도·자동이체일·예산 사용 기준 등을 적을 수 있으며 카드에서도 확인할 수 있습니다.

각 카드의 **추가 메모**에서는 댓글처럼 여러 정보를 날짜별로 남기고 수정·삭제합니다. 한 메모는 최대 3,000자, 기본 설명은 최대 5,000자입니다. 메모는 최근 작성 순으로 50개씩 읽습니다. 수정 시 수정 시각도 표시합니다. 보관 계좌에도 메모를 남길 수 있습니다.

재정의 개인 전용 권한을 그대로 적용하며 다른 공간 멤버에게 공개하지 않습니다. 예산 삭제 시 해당 예산 메모도 함께 삭제됩니다. 기본 설명은 수정 화면에서 편집하고 추가 정보는 메모로 차곡차곡 남기는 용도입니다.

## 데이터와 백업

마이그레이션 0009는 기존 entity_type에 activity/place를 추가하고, 계좌·예산에 기본값이 빈 문자열인 설명 필드를 추가합니다. finance_comments 테이블은 계좌 또는 예산 하나만 참조하며 RLS와 직접 접근 회수를 적용합니다. 거래 금액과 잔액 계산은 변경하지 않습니다.

백업 **v5**는 관계·재정 설명·메모를 보존하며 v1~v4도 읽고 복원합니다. 기존 v4에서 설명이 없으면 복원 시 빈 설명으로 처리해 내용 비교를 이어갑니다. 독립 검증 DB에서 새 관계·설명·메모의 체크섬과 기존 v4 복원을 검증합니다.
