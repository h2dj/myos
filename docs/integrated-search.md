# 통합 검색과 관계별 조회

`/search`에서 현재 선택한 공간의 할 일·프로젝트·상시 활동·노트를 제목/이름과 내용으로 검색한다. 검색어 없이도 관계별 목록을 조회할 수 있다. 완료·취소한 할 일은 포함하고 휴지통은 제외한다. `%`, `_`, `\`는 검색 연산자가 아니라 입력한 문자로 검색한다.

- 프로젝트 선택: 직접 연결한 할 일·노트와 선택한 프로젝트를 조회한다. 기본값은 모든 하위 프로젝트 포함이며 직접 연결 항목만으로 변경할 수 있다.
- 활동 선택: 직접 연결한 할 일과 해당 활동을 조회한다.
- 활동처 선택: 할 일 자체의 활동처와 활동의 기본 활동처를 각각 조회한다. 활동의 기본 활동처를 할 일에 자동 상속해서 검색하지 않는다.
- 여러 필터는 AND 조건이다. 프로젝트·활동 필터를 함께 지정하면 두 관계가 모두 있는 할 일만 나온다. 프로젝트·노트에 활동 관계를 추정해서 붙이지 않는다.

프로젝트 상세의 전체 항목 조회 링크, 사업·활동과 활동처 목록의 이름에서 바로 필터된 검색으로 이동할 수 있다. 결과의 활동을 누르면 해당 활동의 할 일 목록으로 이동한다. 할 일 결과는 날짜/완료 상태에 관계없이 별도 상세 편집 화면을 연다.

필터와 페이지는 URL에 저장하여 새로고침·공유·브라우저 이동에서 유지한다. 검색·관계 필터는 SQL에서 페이지 제한 전에 처리하고 수정 시각 내림차순, 종류, ID 순으로 페이지당 20개를 제공한다. 페이지 이동 중 데이터가 수정되면 위치가 바뀔 수 있다. 현재 최대 500페이지까지 탐색하며 더 많은 결과는 검색어나 관계 필터로 좁힌다.

권한 검사를 먼저 수행하고 모든 검색 분기를 공간 ID와 삭제 상태로 제한한다. 다른 공간 또는 삭제된 관계를 지정하면 결과를 노출하지 않는다. 기존 DB 구조를 사용하므로 별도 마이그레이션이 없다. 부분 문자열 검색은 현재 ILIKE로 처리하며 데이터 증가 시 실제 실행 계획을 측정한 뒤 pg_trgm 인덱스 도입을 판단한다.
